# 背景スケッチはページの中で動かさず、画像に焼き込んで入れる

利用者が貼るか LLM が書いた計算式 (p5.js 風のスケッチ) で、ページの背景を描きたい。いちばん素直なのはスケッチのコードをページに入れて動かすことだが、ページは CSP (`script-src` は Tailwind の URL だけ) で守っており、それを緩めると LLM や他人が書いたコードがページの中で動く。そこで、スケッチはアプリの中の sandbox の iframe (allow-scripts だけ) にある Worker で動かし、テーマの色で色付けした止まった画像 (WebP の `data:`) にしてから、ページの `<style>` に差し込む。CSP は今のまま (`img-src data:` で入る)。p5.js 本体は読み込まず、よく使う関数だけを自前で用意する。

## Considered Options

- ページの CSP に p5.js の URL とインラインのスクリプトを足して、そのまま動かす: 動きは再現できるが、ページの守りが崩れる
- 連番の画像やアニメーションの WebP にする: 動きは近づくが、ページが重くなる。動きは CSS でゆっくり動かす程度にとどめる

## Consequences

- 書き出したページの背景は止まった画像で、スケッチの動きそのものは、作業台の中のプレビューでしか見えない
- 自前で用意していない関数を使うスケッチは動かない (エラーで知らせる)
- 背景を変えても、ページは作り直さずに差し込み直すだけで済む
