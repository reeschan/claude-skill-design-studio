# 案の混ぜ方は、軸ごとのパッドの重みで連続にし、計算は core の 1 か所に置く

これまでは混ぜる軸ごとに案を 1 つ選ぶだけで、度合いは選べなかった。利用者が度合いまで選べるよう、軸ごとに 4 隅へ 4 案を置いたパッドを置き、点の位置から重みを出して混ぜる。色相は円周上で平均し、角丸・余白・彩度・コントラストは重みで平均する。フォント・配置・ライト/ダーク・影は混ぜると意味が無くなるので、その軸で一番重い案に吸着させる。重みと混ぜる計算は、画面ではなくサーバー側の `core/direction.ts` だけで行い、画面は点の位置を送る。画面とサーバーで計算が食い違うと、プレビューと書き出したテーマがずれるためである。

## Consequences

- `/api/mix` の入力は、案の添字ではなく軸ごとの点の位置になる。保存の形式も点の位置を持つ
- フォントや配置は、パッドの上で連続に動かしても途中で切り替わる。どの案が効いているかを画面に出す
