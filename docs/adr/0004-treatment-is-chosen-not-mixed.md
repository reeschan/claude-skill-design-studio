# 表現 (面と動き) は、スタイルとは別の軸として利用者が選び、混ぜない

Material・Glass・Solid や Animated のような表現を、見本帳のスタイル (配色とフォントの型) に足すのではなく、別の軸としてプロジェクトに 1 つ持つ。スタイルに足すと「和モダン × Glass」のような組み合わせの数だけスタイルが要り、方向性の案にも混ぜられなくなるためである。表現は混ぜる軸に入れず、利用者が明示的に選ぶ。面どうし (Glass と Solid の中間) や動きの度合いは混ぜても意味をなさず、パッドで吸着させるだけなら選ばせたほうが分かりやすい。表現は方向性の案を出すときの条件として渡すが、変えても案は出し直さない。

## Consequences

- 骨組みには面だけを CSS の層で効かせ、動きは入れない。骨組みは案を同じ条件で速く見比べるためのもので、動きがあると比べにくくなる
- 保存したページ・部品帳・部品は、作ったときの表現を 1 件ごとに残す。プロジェクトの表現をあとで変えても、昔の 1 件の表現は変わらない
